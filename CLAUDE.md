## Структура проекта
```
index.html        — весь сайт в одном файле: CSS в <style>, весь JS в одном <script> (vanilla ES5, IIFE)
docs/docs.json    — список документов раздела «Документация» (fetch, нужен http-сервер)
docs/*.pdf        — сами документы (nexus-overview.pdf — заглушка)
```
Сборщиков, фреймворков и зависимостей нет. Шрифты подключены с Google Fonts:
- Unbounded — заголовки (`--display`);
- Onest — текст (`--body`);
- JetBrains Mono — моно (`--mono`).

Локальный просмотр: `python3 -m http.server 8000`. При открытии через `file://` раздел документов не загрузится.

1. **Инфобар** — логотип, реквизиты, копируемые контакты `.ct-copy`. Почта и телефон копируются по клику, mailto не используем.

3. **Hero** — «Разработка на скорости нового времени».
   - Камера на поворотной подвеске: SVG `.cam-rig`, физика сервоприводов на PD-регуляторе.
   - `canvas#beam`: еле видимый луч и красная точка под курсором (радиус 2.6 px). Прицельной сетки нет — её убрали.
   - Терминал `#term`: каждые 10 с меняется деплой из массива `RUNS` со сдвигом вправо.
4. **`#appeal`** — обращение к посетителям: опыт команды × ИИ, честные условия, призыв прислать смету текущего подрядчика для встречного предложения.
5. `section.manifesto` → `#approach` (6 принципов) → `section.speed`.
6. **`#products`**:
   - карточка Nexus с живым мини-превью СИ (`#siTeaser`, `#tzMap`), по клику открывает панель;
   - карточка AltGeo (`#altOpen` → модалка `#altModal`, анимация `drawAlt()`).
7. `#docs` → `#directions` → `#contact` (большие копируемые кнопки `.cbig`).
8. **`aside#drawer`** — панель NEXUS справа.
   - Вертикальная вкладка `#drawerTab`, подсказка `#tabHint`.
   - Открывается только по клику, автоматически не открывается. На ширине ≥901px класс `body.si-open` сдвигает контент.
   - Состояния вкладки: idle — дыхание; warn — умеренный жёлтый; alarm — красный, чуть ярче жёлтого. Двойная вспышка раз в 3 с.
   - При первом инциденте звучит двойной бип через Web Audio.
9. Модалки: `#repModal` — отчёт примерно 20×20 см со скачиванием .txt; `#altModal`.

## Симуляция СИ (в `<script>`, блок «NEXUS СИ»)
- **Здание:** 8 одинаковых этажей. Сетка навигации GX=120 × GY=48, поиск пути BFS без срезания углов, сглаживание траектории. Стены непроходимы, двери — проёмы. Есть переходы на лифтах.
- **Время:** `SPEED = 30` (1 с реального времени = 30 с в здании), старт в 09:45.
- **Роли агентов:** guard, post, elec, plumb, clean, tenant, visitor, intruder. Цвет — по группе. BLE-метки привязаны к ФИО.
- **Сценарии:**
  - обходы охраны раз в час по очереди, пропуски фиксируются в журнале;
  - уборка, осмотры, заявки сантехникам и электрикам;
  - посетители с пропусками;
  - сотрудник без метки (Ершов) опознан по камере;
  - нарушитель: потеря видео → поиск по Wi-Fi, BLE и аудио → задержание.
- **Арендаторы (52):** приход 09:47–10:25, обед 11:54–12:12, возвращение 12:46–13:08.
- **Камеры:** 11 на этаж с конусами обзора. Попавший в зону точку подсвечиваем, но в журнал пишем только сотрудника без метки (один раз на этаж, `o.camFl`) или нарушителя.
- **Журнал:** очередь — одна строка в 2.8 с. Время записи фиксируется в момент события. Классы: alert, good, alt, warn. На экране показывается один этаж, переключение — через `focusFloor()`.
- **Ограничение владельца:** в СИ только события, связанные с перемещением людей. Температуру и прочие датчики не добавлять.

## Подводные камни (уже наступали)
- Имя `focus` занято переменной. Функция называется `focusFloor`; DOM-методы `.focus()` не трогать при массовых заменах.
- После правки разметки проверяй баланс тегов. Однажды терялся закрывающий `</div>`.
- `font: inherit` на `.cbig` ломал размеры — не возвращать.
- Аргументы `arc()` на узких экранах могут стать отрицательными. Радиусы оборачивать в `Math.max(0, …)`.
- Пульсирующая вкладка мешает автокликам в Playwright — используй `force=True`.
